# نصب n8n برای کنسول داشبورد

ادیتور واقعی n8n فقط با نسخهٔ self-hosted داخل داشبورد باز می‌شود، چون باید هدر `X-Frame-Options` را روی پروکسی عوض کنیم. n8n به Docker و یک سرور همیشه‌روشن نیاز دارد و روی GitHub Pages، Vercel یا Workers اجرا نمی‌شود.

## نصب

```bash
cp .env.example .env
# N8N_DOMAIN و N8N_ENCRYPTION_KEY را پر کنید
docker compose up -d
```

فایل `nginx.conf.example` را با دامنهٔ خودتان تنظیم کنید و برای دامنه گواهی TLS بگیرید. بعد از اولین ورود، حساب مالک را بسازید و از Settings یک API key تولید کنید.

## محدودیت‌ها

- سایت روی `github.io` و n8n روی دامنهٔ دیگری است، پس کوکی ورود n8n بین‌سایتی حساب می‌شود. Chrome و Edge آن را با `SameSite=None` قبول می‌کنند، ولی Safari معمولاً نه. داشبورد برای همین لینک «باز کردن در تب جدا» دارد. اگر سایت و n8n زیر یک دامنهٔ اصلی بروند، این محدودیت از بین می‌رود.
- مجوز n8n، یعنی Sustainable Use License، استفادهٔ شخصی و داخلی را مجاز می‌داند. این نصب فقط برای مالک است. اگر قرار شد مشتری‌ها یا کاربران دیگر با این ادیتور کار کنند، به مجوز Embed نیاز است.
- پروکسی فقط اجازهٔ قرارگرفتن در iframe را عوض می‌کند. n8n همچنان ورود خودش را دارد و باید با رمز قوی محافظت شود.
