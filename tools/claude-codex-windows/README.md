# اتصال Claude Code و Codex روی ویندوز

این بسته Claude Code و Codex CLI را روی کامپیوتر خودتان به هم وصل می‌کند. هر دو با همان کاربر ویندوز اجرا می‌شوند، پس به همان فایل‌ها، git و ssh-agent دسترسی دارند. هر کدام با حساب خودش وارد می‌شود و هیچ رمز، کلید یا توکنی بین آن‌ها جابه‌جا نمی‌شود.

## نصب (یک بار)

1. اگر Node.js ندارید، نسخه‌ی LTS را از <https://nodejs.org> نصب کنید.
2. Claude Code را نصب کنید: <https://code.claude.com/docs/en/setup>
3. این پوشه (`tools/claude-codex-windows`) را روی کامپیوترتان دانلود کنید.
4. PowerShell را با **Run as administrator** باز کنید (فقط برای روشن کردن ssh-agent لازم است) و بزنید:

   ```powershell
   cd <مسیر این پوشه>
   powershell -ExecutionPolicy Bypass -File .\setup.ps1
   ```

   اگر Codex فقط از طریق پروکسی Hiddify به اینترنت می‌رسد، پورت محلی پروکسی را بدهید. این پروکسی فقط برای همین اجرا تنظیم می‌شود:

   ```powershell
   powershell -ExecutionPolicy Bypass -File .\setup.ps1 -Proxy http://127.0.0.1:<پورت>
   ```

5. اگر مرورگر برای ورود Codex باز شد، با حساب ChatGPT خودتان وارد شوید.
6. اگر اسکریپت گفت کلید SSH در ssh-agent نیست، یک بار `ssh-add` بزنید و passphrase را خودتان وارد کنید.

آخر کار، اسکریپت هر دو ایجنت را با یک سؤال واقعی تست می‌کند. فقط وقتی `DONE` چاپ کرد اتصال برقرار است.

## اسکریپت چه می‌کند

| مرحله | کار |
|---|---|
| ۱ | اگر Codex CLI نصب نباشد نصبش می‌کند و نصب بودن Claude Code را بررسی می‌کند |
| ۲ | سرویس ssh-agent ویندوز را روشن می‌کند تا هر دو بدون دیدن کلید خصوصی بتوانند `ssh` و `git push` بزنند |
| ۳ | اگر Codex وارد حساب نشده باشد، `codex login` را اجرا می‌کند (در مرورگر خود شما) |
| ۴ | اسکیل `codex` را در `%USERPROFILE%\.claude\skills\codex` نصب می‌کند |
| ۵ | قوانین مشترک (`shared-rules.md`) را به `~\.claude\CLAUDE.md` و `~\.codex\AGENTS.md` اضافه می‌کند و از فایل‌های قبلی نسخه‌ی پشتیبان (`.bak-*`) نگه می‌دارد |
| ۶ | تست سلامت: هر دو باید جواب غیرخالی و درست بدهند |

اجرای دوباره‌ی اسکریپت امن است: بلوک قوانین مشترک جایگزین می‌شود و تکراری نمی‌شود.

## استفاده

داخل Claude Code بنویسید:

> از Codex برای این کار نظر دوم بگیر: …

یا مستقیم در PowerShell:

```powershell
& "$env:USERPROFILE\.claude\skills\codex\ask-codex.ps1" -Dir D:\path\to\repo "این باگ را بررسی کن"
git diff | & "$env:USERPROFILE\.claude\skills\codex\ask-codex.ps1" "این diff را review کن"
```

## پسوردها

پسوردها را در یک مدیر رمز با خط فرمان نگه دارید، مثل Bitwarden (`bw`) یا 1Password (`op`). هر ایجنت فقط موقع نیاز یک مقدار مشخص را درخواست می‌کند و شما تأیید می‌کنید. پسورد یا کلید خصوصی را در فایل متنی، گفتگو یا ریپو نگذارید، چون هر چیزی که یک ایجنت بخواند به سرور سازنده‌اش فرستاده می‌شود.
