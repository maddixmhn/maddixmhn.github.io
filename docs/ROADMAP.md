# نقشهٔ راه پلتفرم شخصی

هدف: تبدیل سایت استاتیک به یک پلتفرم فول‌استک با هزینهٔ صفر برای میزبانی وب که جایگاه طراح سیستم را نشان می‌دهد، پیام‌ها را به تلگرام می‌رساند و یک داشبورد خصوصی برای پیام، اتوماسیون و ELON دارد.

راه‌اندازی مرحله‌به‌مرحله در [DEPLOY.md](DEPLOY.md) است.

## سفرهای کاربر و معیار پذیرش

| کاربر | کار | معیار پذیرش |
|---|---|---|
| کارفرما یا مشتری | از گوگل وارد می‌شود، نمونه‌کار می‌بیند، پیام می‌دهد | متن صفحه بدون JavaScript در HTML هست؛ پیام فقط با پاسخ `ok:true` موفق اعلام می‌شود |
| مالک | پیام را در تلگرام می‌گیرد و جواب می‌دهد | پاسخ روی پیام تلگرام در ویجت بازدیدکننده نمایش داده می‌شود |
| دولوپر | درخواست همکاری می‌فرستد | درخواست در دیتابیس ثبت و به تلگرام اعلام می‌شود و در داشبورد وضعیت می‌گیرد |
| مالک | وارد داشبورد می‌شود | فقط ایمیل `ADMIN_EMAIL` به API مدیریت دسترسی دارد |
| مالک | n8n را مدیریت می‌کند | ادیتور واقعی در iframe باز می‌شود و گردش‌کارها از داشبورد روشن و خاموش می‌شوند |
| مالک | به ELON OS کار می‌دهد | خواندن و کار داخل سازمان ایجنت‌ها خودکار است؛ هر اقدام بیرونی یا تغییر سیستم زنده قبل از اجرا تأیید می‌خواهد و همه در گزارش ثبت می‌شود |
| مالک آفلاین است | سازمان کار را جلو می‌برد | Paperclip ایجنت ELON OS را با heartbeat بیدار می‌کند؛ کارها تقسیم می‌شوند و اگر تأیید لازم شد، کار مسدود و به تلگرام خبر داده می‌شود |

## جهت بصری

الهام از پالت تلسکوپی سحابی‌ها: هیدروژن آلفا `#ff5c7a`، اکسیژن `#43d9cf` و گوگرد `#f5b94c` روی زمینهٔ `#0b0e28`. عنصر اصلی یک پشتهٔ شیشه‌ای سه‌بعدی از چهار لایهٔ سیستم است که با اسکرول از هم باز می‌شود. Bricolage Grotesque برای لاتین و Vazirmatn برای فارسی.

حالت‌های خطا، خالی، بارگذاری، موبایل و `prefers-reduced-motion` برای همهٔ صفحه‌ها پوشش داده می‌شوند. روی موبایل پشته ثابت است و بخش‌ها زیر هم می‌آیند.
